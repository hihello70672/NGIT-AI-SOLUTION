# Phase agent assignments

Assignments identify accountable owners and collaborators; they do not prove completion. The approved specification names 19 specialist assignments. Chief Architect coordinates the twentieth role for architecture review; this does not create an unrequested implementation module or repository agent.

## Coordination expectations

- Module owners remain accountable for their contracts, implementation, tests, dependencies and status reporting.
- Inspect shared interfaces and current code before extension; preserve working paths and avoid duplicate services or empty scaffolding.
- Shared-contract, dependency, or boundary changes require Chief Architect review.
- Derive caller identity server-side; enforce ownership, audit and required approval for every capability.
- Record exact test commands and results only after execution. Checked-in tests alone are not evidence of passing tests.
- External AI providers remain optional. Windows, Kali and Android are not deliverables in this web-first milestone.
