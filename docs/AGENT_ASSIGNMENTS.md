# Phase agent assignments

Assignments define accountable owners and collaboration, not evidence of completion. The approved architecture names 19 specialist assignments; the Chief Architect coordinates cross-contract review as the twentieth role, without adding an implementation module.

Security Architect reviews tenant/security foundation. QA defines gates and reports only executed evidence. Frontend aligns web boundary/API needs. |

## Coordination expectations

- Module owners remain accountable for their contracts, code, tests, dependencies and status.
- Inspect existing code and interfaces before extension; preserve working paths and avoid duplicate services or empty scaffolding.
- Shared contract/dependency/boundary changes require Chief Architect review and interface-doc updates before downstream integration.
- Derive caller identity server-side; enforce ownership, audit and required approval for every sensitive capability.
- Record commands/results only after test execution. Test files alone are not passing evidence.
- External AI stays optional. Windows, Kali and Android clients are outside this web-first milestone.
